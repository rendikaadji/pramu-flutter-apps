# pramu_apps

App Flutter (Android + iOS) — marketplace Pencari ↔ Asisten.

> **Sebelum coding, baca [`docs/00-Panduan-Alur-Kerja.md`](docs/00-Panduan-Alur-Kerja.md)** — alur lengkap dari clone sampai push branch baru, plus daftar dokumen wajib baca.

## Mulai cepat

```bash
git clone https://github.com/rendikaadji/pramu-flutter-apps.git pramu_apps
cd pramu_apps
flutter pub get
flutter run
```
